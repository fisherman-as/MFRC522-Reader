Чтобы получить считанный номер карты с RFID-модуля MFRC522, нужно выполнить следующие шаги:

Инициализация модуля:

Настройте связь с MFRC522 по SPI.
Выполните программную инициализацию модуля (например, сброс, настройка таймеров).
Подача команды к поиску карты: Отправьте команду PICC_REQIDL для поиска карты в пассивном режиме. Это команда для поиска карты, не находящейся в спящем режиме. В ответ модуль сообщит о наличии карты в зоне действия.

c
Копировать код
MFRC522_Request(PICC_REQIDL, bufferTagType);
Антиколлизия и получение UID: Отправьте команду PICC_ANTICOLL для выполнения антиколлизии и считывания уникального идентификатора (UID) карты. UID — это номер карты.

c
Копировать код
MFRC522_Anticoll(bufferUID);
Вывод UID карты: После выполнения команды антиколлизии (антиконфликтного алгоритма) данные UID сохраняются в буфере. Обычно UID карты имеет длину 4 или 7 байтов (в зависимости от типа карты).

Пример кода на C
c
Копировать код
uint8_t status;
uint8_t str[MAX_LEN];
uint8_t cardUID[5]; // UID карты (максимум 4 байта + CRC)

// Инициализация модуля
MFRC522_Init();

// Поиск карты
status = MFRC522_Request(PICC_REQIDL, str);
if (status == MI_OK) {
    printf("Карта найдена\n");
}

// Антиколлизия
status = MFRC522_Anticoll(cardUID);
if (status == MI_OK) {
    printf("UID карты: ");
    for (int i = 0; i < 4; i++) {
        printf("%02X ", cardUID[i]);
    }
    printf("\n");
}
Команды для MFRC522:
PICC_REQIDL: Поиск карты.
PICC_ANTICOLL: Антиколлизия и считывание UID.
MI_OK: Статус успешного выполнения.
